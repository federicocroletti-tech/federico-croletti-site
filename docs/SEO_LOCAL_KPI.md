# KPI Local SEO

## Baseline settembre 2026

- 126 visualizzazioni del Profilo dell'attivita.
- 57 ricerche.
- 1 interazione.
- 1 clic per la chat.
- 0 chiamate.
- 0 visite al sito dal profilo.

Questi dati sono una baseline indicativa, non un funnel perfetto.

## Obiettivi indicativi a 90 giorni

Non sono garanzie di risultato:

- 180-250 visualizzazioni del profilo.
- 80-120 ricerche.
- 5-10 interazioni.
- 3-8 clic al sito.
- 3-6 chiamate o chat qualificate.
- Almeno 4-6 query pertinenti non legate al nome.
- 3-6 nuove recensioni autentiche.

## KPI da monitorare

- Visualizzazioni del Profilo dell'attivita.
- Ricerche.
- Query non legate direttamente al nome.
- Clic al sito.
- Telefonate.
- Chat.
- Richieste di contatto.
- Visite alla landing locale.
- Tasso di conversione della landing.
- Provenienza dei contatti.
- Nuove recensioni autentiche.
- Posizionamento per query professionali.
- Posizionamento per query locali.
- Performance Lighthouse.
- Core Web Vitals.
